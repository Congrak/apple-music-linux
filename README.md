# 🎵 Apple Music for Linux

A lightweight Electron wrapper around music.apple.com — no API keys, no $99 developer account, just your Apple Music subscription.

## Setup & Run

```bash
npm install
npm start
```

## Build a distributable (.AppImage or .deb)

```bash
npm run build
```

The output will be in the `dist/` folder.

## Requirements
- Node.js
- An Apple Music subscription
- That's it!
